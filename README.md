# Mac reader kit · Git & GitHub for Scientific Computing and Writing

Prepared files for the Mac edition of the book, by lab and step. **Download the ZIP from
[Releases](https://github.com/noctis-oss/git-github-mac-kit/releases/latest)**
(`mac-reader-kit-v1.zip`), unzip it in Downloads, outside your project, and copy only the file a
step names. How to use each stage: [README-EN.md](README-EN.md).

This is material to copy, not a repository to clone: your own project and its history are the
work of the book. Reference histories to compare with, once you have tried each lab:
[heat-transfer-1d](https://github.com/noctis-oss/heat-transfer-1d/tree/mac-edition) (Labs 2–11)
and [kepler-orbits](https://github.com/noctis-oss/kepler-orbits/tree/mac-edition) (Lab 12),
branch `mac-edition`.

del libro. Historiales de referencia para comparar, después de intentar cada laboratorio:

[kepler-orbits](https://github.com/noctis-oss/kepler-orbits/tree/mac-edition) (Lab 12), rama
